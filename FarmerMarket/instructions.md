# FarmerMarket Homework

Download the zip file to your desktop, unzip it, and open the folder in VS Code. Run the page with Live Server (**Go Live**) and try it out.

Study the code of the FarmerMarket homepage and answer these questions:

1. How many children does the `<nav>` container have?
   Answer: 2 (the <img> and the <div class="link">)

2. How many children does `<section class="card-box">` have?
   Answer: 2 (<div class="card farmer"> and <div class="card cow">)

3. Name the 3 id selectors used to jump from the navigation to the 3 sections.
   Answer: #home, #menu, #contact

4. What is the `<nav>` background-color in the CSS?
   Answer: darkgrey
